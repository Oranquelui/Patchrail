# Patchrail v0.2.0-alpha.1 Release Report

## 1. Release Intent

This alpha consolidates the development work after `v0.1.0` and updates the public direction toward a skill-first, CLI-backed Patchrail workflow.

The release deliberately separates:

1. Implemented alpha contracts.
2. Public product direction.
3. Next implementation priorities.

## 2. Implemented In This Release

1. Brief Schema v1 for persisted planning briefs and plan references.
2. `patchrail brief validate` for read-only brief readiness checks.
3. Runner Contract v1 for shell runner handoff and CLI inspection.
4. Evidence Bundle v1 for post-run manifest metadata and schema markers.
5. Runner-local artifact collection into canonical Patchrail evidence storage.
6. Local smoke flow that creates all three briefs, validates them, runs, reviews, and approves from local state.
7. First public `patchrail-supervise` Agent Skill scaffold.

## 3. Direction Updated

The next release line focuses on reducing approval fatigue:

1. `ApprovalProfile v1` for `auto`, `ask`, and `deny` action classes.
2. `RunLedger v1` for action receipts, escalations, denials, and rollback notes.
3. Codex plugin packaging for the `patchrail-supervise` skill after the scaffold is validated.
4. Effective native approval-mode capture from supported coding-agent hosts where possible.

## 4. Explicitly Not Claimed

This release does not claim runtime implementation of `ApprovalProfile v1` or `RunLedger v1`. Those are documented as next implementation targets.

Skill instructions are also not treated as enforcement. Enforcement must come from host-agent permissions, sandbox settings, Patchrail policy records, hooks where available, and local evidence.
